# NOS Teletekst — E-ink

A minimal Android app for reading NOS Teletekst with an e-ink aesthetic.  
Clean, distraction-free, monospace — designed to feel like reading on paper.

## Features

- Browse all NOS Teletekst pages
- Subpage navigation via swipe or arrow buttons
- Back button with full browsing history
- Visited articles marked in italic
- Minimal e-ink design — paper white, ink black, monospace font
- No ads, no tracking, no clutter

---

## Installation

1. Download `eink-teletekst-1.0.apk` from the [Releases](https://github.com/EXPELER/NOS-Teletekst-Eink/releases) page
2. On your Android device, go to **Settings → Install unknown apps** and allow installs from your browser or file manager
3. Open the downloaded APK and tap **Install**

**Requires Android 8.0 (Oreo) or higher**

## Built With

- [Kotlin](https://kotlinlang.org/) + [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Retrofit](https://square.github.io/retrofit/) — API calls
- [Jsoup](https://jsoup.org/) — HTML parsing
- Data from [teletekst-data.nos.nl](https://teletekst-data.nos.nl)
